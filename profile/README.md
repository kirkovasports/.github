# Kirkova Sports

Sports scores, picks and prop-bet milestones with every result graded in public, plus our own native fantasy. Web at [kirkova.cc](https://kirkova.cc), and an iOS app.

## Open source

| Repository | What it is |
|---|---|
| [kirkova-models](https://github.com/kirkovasports/kirkova-models) | How our prediction models are trained and judged: code, papers, accuracy reports and the full training history |
| [kirkova-api-docs](https://github.com/kirkovasports/kirkova-api-docs) | The public API reference |

Found something wrong, or want to suggest an improvement? Open an issue on the relevant repository. Bug reports about the website or app are welcome in any of them too.

Predictions are for entertainment only, not betting or financial advice.
